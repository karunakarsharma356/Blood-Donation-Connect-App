# 🩸 Blood Donation Connect

A full-stack **MERN Stack** application designed to simplify the blood donation process by connecting blood donors with recipients through a secure and user-friendly platform. The project aims to reduce the time required to find suitable blood donors by providing an efficient donor management system. Users can register donor information, manage donor records, and easily access available donors whenever required. The application follows the **MVC architecture** and is built using modern web technologies to ensure scalability, maintainability, and a smooth user experience.

---

## ✨ Features

The application currently supports complete **CRUD operations** for donor management, allowing users to add, update, view, and delete donor records. It uses **MongoDB Atlas** as the cloud database and exposes well-structured **REST APIs** developed with **Node.js** and **Express.js**. The backend follows the **MVC design pattern**, making the project modular and easy to maintain.

Future enhancements include secure **JWT Authentication**, user registration and login, blood request management, donor search based on blood group and location, protected routes, and a fully responsive React frontend.

---

**Backend:** Node.js, Express.js

## ⚙️ Getting Started

Clone the repository and install the required dependencies.

```bash
git clone https://github.com/dikshaverma469/Blood-Donation-Connect-App.git
cd Blood-Donation-Connect-App/server
npm install
```

Create a `.env` file and add the required environment variables.

```env
PORT=5000
MONGO_URI=YOUR_MONGODB_CONNECTION_STRING
JWT_SECRET=YOUR_SECRET_KEY
```

Start the development server using:

```bash
npm run dev
```

The server will run on:

```text
http://localhost:5000
```
